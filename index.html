The system

Every word.
One stroke.

Twenty-five cells. Twenty-five letters. Each word becomes a single path across the grid — starting at the first letter, passing through every letter in sequence, ending at the last. Any word. Any length. One mark.

01
Map letters to positions
A–Z fill 25 cells in reading order. Q shares X's position. Every letter has one fixed coordinate — no ambiguity, no exceptions.
02
Trace the path
Draw a line connecting each letter's position in order. A filled dot sits on the first letter. An arrowhead is centred on the last.
03
Mark double letters
Consecutive duplicate letters collapse to one node. A small white circle marks that node — distinguishing "to" from "too," "of" from "off," with no ambiguity.
04
Read it back
Follow the path node by node. Each position maps back to a letter. With practice the entire shape reads as a single unit — the way a skilled reader sees a whole word, not its letters.

The reference grid

The key to everything

The 5×5 grid is the only reference a reader needs. Every LINES symbol can be decoded by anyone who has this grid — no software, no internet, no electricity. Print it once and the entire system is recoverable forever.

This is the fundamental archival advantage over algorithmic compression: a gzip file without a decompressor is permanently unreadable. A LINES document with a printed grid is recoverable by any literate person.

Q / X
Q is absent from the grid and shares X's position. Any word containing Q is encoded using X's coordinates. Context disambiguates in practice.

Applications

Where LINES fits.

◈
Long-term archival
Documents encoded in LINES are recoverable by any literate person given only a printed 5×5 grid key. No software dependency, no format obsolescence, no decompressor required.
◎
Private notation
Field notes, journals, and clinical records written in LINES are illegible to untrained readers — not encrypted, but sufficiently obscured for everyday privacy in public spaces.
◇
Compact print
A LINES glyph occupies the same square regardless of word length. "Uncomfortable" and "it" take identical space. Page density increases dramatically for long-word-heavy text.
▷
Rapid handwriting
Every word is a single connected stroke. A trained writer produces any word in one continuous pen motion — faster than printing or cursive for words beyond four letters.
⬡
Data transmission
At 14 bits per common word versus 46 bits in UTF-8, LINES index streams reduce bandwidth by 70% for English text — with no preprocessing overhead beyond a vocabulary lookup.
△
Steganography
LINES index streams embedded in images or documents are invisible to casual inspection but machine-readable with the vocabulary key — a natural fit for watermarking and covert channels.

System specification

LINES 1.1
Formal rules.

Rule 1 — The Grid

A 5×5 grid holds 25 cells, labelled A–Z in reading order. Q is absent and shares X's position at row 4, column 2. Each cell has a fixed coordinate: row 0–4 (top to bottom), column 0–4 (left to right).

Rule 2 — Encoding a Word

Each word becomes a single connected path. Map each letter to its grid node, connect the nodes in sequence, and mark start and end.

01Map each letter to its grid coordinate. Consecutive duplicate letters collapse to one node.
02Draw a line connecting each node in order.
03Place a filled dot at the first letter's node.
04Place an arrowhead with its base midpoint centred on the final letter's node. The tip extends beyond the node.
05If any letter repeats consecutively, place a small open circle directly on that letter's node.
Rule 3 — Reading a Symbol

Locate the filled dot (first letter). Follow the line through each node. The arrowhead's base midpoint marks the last letter. A white circle at any node indicates a doubled letter there.

Rule 4 — Sentences

Words are placed left to right with consistent spacing. Punctuation is inserted inline at the same height as the symbols. Word boundaries are implied by the discrete marks — no spaces are encoded.

Rule 5 — Disambiguation
Double letters collapse to one node and receive a white dot marker. "LETTER" has two T's: the T node appears once, marked.
Q always uses X's node. Context disambiguates.
Single-letter words are a filled dot only — no line, no arrowhead.
Two letters at the same node (e.g. "XX") become a single-node word with a white dot.
Rule 6 — Proportionality

All elements scale with SIZE (canvas pixel width). PAD = SIZE × 0.06. CELL = (SIZE − 2×PAD) ÷ 5.

Rule 7 — What LINES Is Not
Not a cipher. The encoding rule is public and derivable from the grid alone.
Not phonetic. Letters map to positions; pronunciation is not encoded.
Not a lookup system. Any word is encodable from the grid with no dictionary.
